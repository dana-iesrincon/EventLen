# EventLen

EventLen es una aplicación web orientada a la consulta, gestión y reserva de eventos de ocio y deportivos.

## Objetivo

El objetivo del proyecto es desarrollar una aplicación web funcional que permita a los usuarios consultar eventos disponibles y realizar reservas para participar en ellos.

## Tecnologías previstas

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- Git
- GitHub
